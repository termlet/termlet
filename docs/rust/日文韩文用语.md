# 日文、韩文用语

> 界面的日文（`ja`）与韩文（`ko`）按本文翻译：以简体中文为准，对照英文理解意思，用语参照 Windows、macOS、VS Code 与常见 SSH 客户端（Termius 等）在日本、韩国的叫法。改文案时，`crates/termlet-desktop/locales/*.yml` 中同一个键的 `zh-CN`、`en`、`zh-TW`、`ja`、`ko` 一起改。危险命令内置规则的说明（核心的 `guard/rules.rs`）同样按本文。命令行工具 `termlet` 只有简体中文与英文。
>
> 译文由开发者整理，没有经过母语者逐条审校；欢迎指出不自然的说法。改了某个词的译法要全篇一致，并更新下面的对照表。

## 共同的格式

- 插值 `%{name}` 原样保留，名称、个数与中文相同（`i18n.rs` 的 `locales_are_complete` 检查）。
- 原文的换行 `\n`、Markdown、反引号中的代码、命令、路径、键名（Ctrl、Enter、Tab、⌘）照原文。
- 英文专有名词、产品名、协议名（SSH、SFTP、Telnet、ZModem、trzsz、WebDAV、TOTP、MCP）、Agent Skill 照原文，不音译。
- 一句对一句，不增删意思；按钮、菜单项、表头尽量短。原文以“。”结尾的句子译文也以句号结尾，标签、按钮、标题不加句号。
- 不用人称：原文的“你”在日文、韩文中一般省略（不写「あなた」「당신」），需要时日文用「お使いの」，韩文直接省去。
- 英文有单复数之分而中文没有的，日文、韩文都用同一句。
- 引用界面上的名称（中文原文写作“更改设置”）时，用那个按钮、菜单项本身的译文，不另译。
- 中文的句子之间不加分隔符：`close.sentence_separator` 的日文为空字符串（与中文相同），韩文为一个空格（与英文相同）。

## 日文

### 语气与格式

- 句子用です・ます体：说明「〜します。」「〜できます。」，请求「〜してください。」，确认「〜しますか？」，失败「〜できませんでした：%{error}」。
- 按钮、菜单项、标题用体言止め或简短的动词原形：「保存」「削除」「開く」「閉じる」「再接続」「新しいタブで開く」。
- 标点用全角：、。「」（）：？！；引号用「」，嵌套用『』，不用 “” 与 ""。列举用「、」，片假名词并列可用「・」。省略号「…」照用。
- 中文的“，”在日文中用「、」；“；”一般改为「。」断句或用「、」连接，不用全角分号。
- 片假名的长音按 Microsoft 的规则：以 -er、-or、-ar 结尾的词加「ー」（サーバー、フォルダー、ユーザー、コンピューター、ブラウザー、エディター、マネージャー、パラメーター、フィルター、コンテナー、プロバイダー、ヘッダー、モニター），以 -ry、-ty 等结尾的不加（ディレクトリ、メモリ、エントリ、カテゴリ、ライブラリ、リポジトリ、セキュリティ、プロパティ）。
- 片假名复合词之间不加空格（ローカルターミナル、ポート転送ルール）。
- 和文与英文、数字之间加半角空格，与中文原文相同（「SSH キー」「%{count} 台」「Termlet を終了」）；全角标点、括号的前后不加。
- 汉字用日本的字形（新字体）：设置→設定、连接→接続、删除→削除、编辑→編集、导出→エクスポート。不出现简体字与繁体字形（「設置」「連線」「檔案」都不用）。
- 数字用半角阿拉伯数字；单位：秒→秒、分钟→分、小时→時間、天→日、字节、MB 照原文；“%{n} 分钟前”→「%{n} 分前」。
- 量词：台（主机、电脑）→台，个、把（密钥）、套（配色）、份（备份）→個，条（记录、历史、审计、规则、转发、快捷命令）→件，次→回，行→行，字→文字。

## 韩文

### 语气与格式

- 叙述用합니다체：「~합니다.」「~할 수 없습니다.」；请求、引导用「~하세요.」（与 Windows、macOS 的韩文界面相同的组合）；确认用「~하시겠습니까?」；失败用「~하지 못했습니다: %{error}」。全篇只用这一套，不混用「~해요」「~한다」。
- 按钮、菜单项、标题用简短的名词形：「저장」「삭제」「열기」「닫기」「다시 연결」「새 탭에서 열기」。
- 标点用半角，与英文相同：. , : ? ! ( )，冒号、逗号、句号后面空一格；括号紧接在前面的词后（「설정(일반)」）。不用全角标点与「」。
- 界面上的名称、用户输入的名字用单引号 `'…'` 引起来（「'%{name}' 호스트를 삭제하시겠습니까?」），引用的原文、字面文字用双引号 `"…"`。
- 띄어쓰기按韩文规范；助词紧接在前面的词后，包括英文与插值：「Termlet을」「SSH 키를」。
- 插值后面需要助词时，尽量接一个固定的名词再加助词（「'%{name}' 호스트를」）；接不了时用两可的写法「을(를)」「이(가)」「은(는)」「과(와)」「(으)로」。Termlet 读作“텀렛”，后接有收音的形式：「Termlet을」「Termlet이」「Termlet은」「Termlet으로」。
- 不用汉字；中文原文里的书名号、全角括号都换成韩文的写法。
- 数字用半角阿拉伯数字，量词紧接数字：「%{count}개」「%{count}대」；单位：秒→초、分钟→분、小时→시간、天→일，英文单位前空格（「%{size} MB」）；“%{n} 分钟前”→「%{n}분 전」。
- 量词：台（主机、电脑）→대，个、把（密钥）、套（配色）、份（备份）、条（规则、转发、快捷命令）→개，条（记录、历史、审计）→건，次→번，行→줄，字→자。
