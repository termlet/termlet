# 繁体中文用语

> 界面的繁體中文（`zh-TW`）用台湾用语，不是逐字转换字形：参照 Windows、macOS 繁体中文版与常见软件在台湾的叫法。改文案时，`crates/termlet-desktop/locales/*.yml` 中同一个键的 `zh-CN`、`en`、`zh-TW` 一起改；英文可以帮助理解原意。安装程序（`packaging/windows/installer.nsi` 的 `LANG_TRADCHINESE`、`license_zh_TW.txt`）与核心中危险命令内置规则的繁体说明（`guard/rules.rs`）同样按本文。命令行工具 `termlet` 只有简体中文与英文。

## 格式

- 插值 `%{name}` 原样保留，名称、个数与中文相同（`i18n.rs` 的 `locales_are_complete` 检查）。
- 标点用全角：，。：；？！照用；引号用「」（嵌套用『』），不用 “” 或 ""（同一个测试检查 “”）；省略号「…」照用。
- 中文与英文、数字之间的空格照原文：原文有空格就留，没有就不加。
- 英文专有名词、产品名、命令、文件名、键名（Ctrl、Enter、Tab）、协议名（SSH、SFTP、Telnet、ZModem、trzsz、WebDAV、TOTP）照原文。AI 照写 AI。
- 原文的换行 `\n`、Markdown、反引号照样保留。
- 人称照原文用「你」，不改成「您」。
- 原文写作英文、指标签页的 Tab 译作「分頁」（「在新的 Tab 中执行」→「在新分頁中執行」）；指 Tab 键时保留「Tab」。
- 字数尽量与原文相当，按钮、菜单项简短。
- 一句对一句，不增删意思。中文的句子之间不加分隔符：`close.sentence_separator` 的繁体与简体一样是空字符串。

## 最终定下的说法

下面几处译者之间曾不一致，最后统一为台湾开发者最常用的说法：

| 简体 | 繁體（台湾） | 不用 |
|---|---|---|
| 监听（端口） | 監聽 | 接聽 |
| 正则表达式 | 正規表示式 | 規則運算式 |
| 区分大小写 | 區分大小寫 | 大小寫須相符 |
| 全词匹配 | 全字比對 | 全字拼寫須相符 |
| 被堡垒机调起 | 由堡壘主機啟動 | 由堡壘主機叫用 |
| 点击 | 按一下 | 點選 |
